01 / Everyday layer

Six small tools. One calm surface.

The interface is designed around things that deserve to be visible without asking for your attention. Each widget stays simple; together they form a flexible desktop composition.

01 / Tasks

To-do list

Add, edit, complete, and remove tasks. The list stays visible while the rest of the desktop remains uncluttered.

02 / Pinboard

Pinned items

Keep important links, words, or items visible with local persistence and a dedicated place.

03 / Schedule

Special activity

Set an activity for a date and let Mosaic surface a reminder when the moment arrives.

04 / Photos

Rotating photo widget

Show local images with subtle transitions so the picture changes while the desktop stays quiet.

05 / Notes

Private Quick Notes

Keep short notes protected locally with Windows data protection and optional device authentication.

06 / Appearance

Make the layout yours

Control widget visibility, transparency, accent, radius, blur, and placement from settings.

04 / Local by design

Useful things stay close.

Mosaic stores its everyday app data locally. Quick Notes can use Windows data protection, keeping the private layer tied to the device account rather than turning the desktop into another cloud service.
